# Contributing

Read [README.md](README.md), [TODO.md](TODO.md), and
[docs/implementation-plan.md](docs/implementation-plan.md) before changing files.
The project is at the initial scaffold stage. Implement one planned task at a
time, preserve unrelated changes, and document meaningful verification results.

Use JavaScript ESM for executable helpers and Node.js for the initial runtime.
Keep local scratch data under `workplace/`; only its `.gitkeep` is tracked.
Follow the shared references linked from
[docs/miku-soft-reference.md](docs/miku-soft-reference.md).
